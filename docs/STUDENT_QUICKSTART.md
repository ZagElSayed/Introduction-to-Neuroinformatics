# Student Quickstart

Welcome to the companion repository for *Introduction to Neuroinformatics*.

1. Browse `chapters/` and select the chapter you are studying.
2. Read that chapter's `README.md` for prerequisites, data sources, and instructions.
3. To download all code, choose **Code → Download ZIP** on the repository homepage.
4. Install Python and Jupyter following the chapter's environment instructions.
5. Run notebook cells in order, inspect plots, and record your observations.
6. Download public datasets from the documented original sources; never commit patient or identifiable data.

**Chapter 1 dataset:** [PhysioNet EEG Motor Movement/Imagery](https://physionet.org/content/eegmmidb/1.0.0/), subject S001, run R01, eyes-open baseline (DOI: 10.13026/C28G6P).

The examples are educational, not clinical diagnostic software.
