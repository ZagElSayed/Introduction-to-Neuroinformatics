## Start simply

Use Python 3.11 or 3.12. Open Notebook 1 and run its cells in order. Notebook setup cells install bounded dependency ranges and load the supplied [helper](vision_studio.py); no application server, paid API, GPU, or pretrained weights are required. Colab resource availability varies. Local Jupyter is an alternative. If a widget frontend does not display, use `studio.show_views(...)` or `studio.inspect_example(...)` directly.

## Scientific contract

Source: [EEG Motor Movement/Imagery Dataset v1.0.0](https://physionet.org/content/eegmmidb/1.0.0/), DOI [10.13026/C28G6P](https://doi.org/10.13026/C28G6P), licensed under Open Data Commons Attribution License v1.0. Cite the release, Schalk et al. (2004), DOI [10.1109/TBME.2004.827072](https://doi.org/10.1109/TBME.2004.827072), and the PhysioNet platform citation requested on the release page. Keep its attribution with derived evidence.

- Runs **R01 eyes open, R02 eyes closed** supply recording-condition labels. These are not motor-imagery T1/T2 labels, diagnoses, or artifact labels.
- Posterior channels O1/Oz/O2 are kept in fixed order, filtered 2–30 Hz with a prespecified fourth-order zero-phase IIR, resampled to 64 Hz, and converted from volts to microvolts. The acquisition reference is preserved.
- Ten nonoverlapping four-second windows per run begin four seconds into each recording. Filtering is within the recording; analysis is retrospective, not streaming/causal forecasting.
- Average channel **power matrices**, not waveforms. A symmetric 64-sample Hann window, hop 16, per-segment mean subtraction, and one-sided PSD normalization produce 33×13 maps; 2–30 Hz leaves **29×13**. Units are microvolt²/Hz; times are segment centers.
- Fixed −20 to 40 dB bounds relative to 1 microvolt²/Hz, floor 1e-12, clipping, rounding, and nearest resizing produce 64×64 grayscale inputs. Highest frequencies are at the top. Images have no axes, text, or target labels; filenames/manifest labels are not model features.
- Train S001–S008, validate S009–S010, test S011–S012. Every person contributes both conditions. The default is 240 windows from 12 people, with explicit errors for missing channels/short recordings rather than silent exclusions.
- The test produces four person-condition means from **two independent people**. No precise population estimate, site transfer, or clinical conclusion follows. Condition is confounded with fixed run order; the experiment cannot isolate those effects.

## Models and interpretation

CNN: two convolutions (8 and 16 filters), average pooling, flattening, Dense(16), one logit. Binary cross-entropy uses logits. Inputs are fixed pixels/255. Adam uses learning rate 0.001, batch size 16, default epoch limit 15. Minimum validation BCE selects weights with patience 3 and min_delta 0; selected weights are restored. The numerical comparator is fixed-C logistic regression on mean log 8–12-Hz and 2–30-Hz PSD, with training-only scaling. These are mean density features, not integrated band power. Mean predictions within person and condition support accuracy, ROC-AUC, and Brier at fixed threshold 0.5. Calibration is assessed, not fitted. Inspect the baseline even when it beats the CNN.

The model file is verified for reloaded inference within the student run. Final-epoch optimizer information can coexist with restored selected weights; full interrupted-training recovery is not established. Initialization/operation determinism is requested, not promised across different packages/hardware.

The review tool uses validation rows and a training-only gallery. Grad-CAM targets the eyes-closed logit or its negative; its 32×32 activation grid remains coarse after enlargement. The 4×4 replacement map sets 16×16 tiles to intensity 128 and reports signed P(closed) changes. Midpoint intensity is not the training mean or absent brain activity. Retrieval uses cosine similarity of flattened trained convolutional features; nearest examples are not diagnostic matches. QC flags describe shape, dtype, constancy, and endpoint fractions without validated physiological thresholds. The fresh random-parameter map is a control, not label-shuffled retraining.

No notebook calls a VLM, estimates clinical artifact classes, removes components, or produces a diagnosis. The hand-authored four-field review example demonstrates reference/schema validation and mandatory pending review. It does not establish factual correctness. Local open-weight VLMs or an authorized API can be an advanced extension with separately specified licensing, prompt, compute, privacy, and evaluation requirements.
