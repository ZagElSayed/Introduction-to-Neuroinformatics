## Defense questions

Explain an accepted request and a refusal to both a medical student and an IT engineer. Why does a high score on an invented noise recipe not establish a usable EEG artifact detector? Why does restoring one request not demonstrate hardware recovery? Which role and network properties were supplied as inputs rather than measured? How would selecting a new threshold from evaluation results change the evidence boundary?

For the next study, choose one bounded extension. A new acquisition adapter needs unit/channel/timing semantics and reference judgments. A cluster interval needs a justified resampling unit. A real API needs evaluated identity, permissions, failures, and observability. A clinical-impact proposal needs an endpoint and comparator beyond classifier accuracy. Treat an appropriate refusal or a carefully explained negative result as useful evidence, not as a reason to hide a run.
