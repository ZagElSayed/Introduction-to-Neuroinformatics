# Reflection and agent card

Write connected paragraphs addressing these questions:

- Which laboratory bottleneck does your assistant address? What would you compare with manual work or an existing pipeline?
- Which branches of your run required a decision? Which computations were delegated to numerical tools?
- Why is this baseline a workflow rather than evidence of LLM reasoning? What would an LLM add, and how would you measure that addition?
- Which records distinguish measured/generated source data, retrieved recipes, calculated values, and human decisions?
- Explain one correctly stopped case and one possible false stop. What additional metadata would resolve the latter?
- What does the malicious-annotation case establish about this implementation, and what does it leave untested?
- Which deployment features remain missing: identity, isolation, crash recovery, timeouts, authenticated review, or real-data validation?

Agent card fields: task and scope; user; prohibited uses; synthetic fixture definition; recipe ID; tool and planner versions; source hash; outputs and states; verification; limitations; evaluation cases and measured results; human review and update plan.
