# Level 2 — Real EEG preprocessing protocol

This is a guided design and local-analysis exercise, not an automated clinical pipeline. Use a dataset with documented permission and a recording suited to the question; a resting recording without the necessary events cannot support a task ERP lab. Keep original files unchanged. Record actual software versions and consult the matching documentation.

1. **Analysis contract and intake:** Specify population, research endpoint, minimum usable duration/trials, frequency/timing needs and review rules before comparing outcomes. Record file identity/hash, units and conversion, sample rate, channel types/names, reference, acquisition filters, montage, auxiliary channels, events and discontinuities. MNE commonly exposes EEG data in volts; convert explicitly when reporting microvolts.
2. **Raw inspection:** Review representative traces, spectra, flatness/saturation, sensor geometry, line interference and event timing. Mark suspect channels and intervals with reasons and reviewer identity. Retain unmodified time/sample coordinates and condition/group denominators.
3. **Filtering comparison:** Preserve matched branches with justified designs. Report cutoff definition, transition bandwidth, length/order, phase, padding and discontinuity handling. Inspect impulse/transient behavior and the intended endpoint. Do not join removed intervals and filter across the new artificial boundary. Use anti-aliasing for downsampling and check event coordinates; simple decimation is not a substitute.
4. **Reference and rank:** Define the actual EEG channels contributing to the reference. Exclude bad and auxiliary channels appropriately. Record applied projectors, dependent/interpolated channels, effective rank and operation order. Check the software rank estimate instead of equating rank with sensor count.
5. **ICA branch, if justified:** Choose enough suitable multichannel data and document convergence. A higher high-pass fit copy may improve fitting; this does not justify using that cutoff for the scientific endpoint. Applying its solution to a differently filtered copy requires matching channel identity/order, scaling, reference and spatial projections/rank. Keep excluded intervals, method, component count, seed and transfer assumptions. Fit without baseline correction; if baseline correction is required for the endpoint, apply it after reconstruction and inspect offsets. Do not transfer weights across changed montages or references without a justified, validated transformation.
6. **Component decision record:** For each reviewed component save scalp map, time course, spectrum, auxiliary-sensor/event evidence, automatic label and score if used, final retain/remove/review decision, rationale, reviewer and versions. Uncertain cases stay reviewable. Removing components can also remove neural activity. Two synthetic channels in Level 1 do not validate ICA.
7. **Epochs and endpoint QC:** Use event/timing and baseline choices justified by the experiment. Report candidate, retained and excluded trials by participant/condition and reason; review unequal missingness. Compare both targeted nuisance metrics and independently chosen scientific endpoints, with uncertainty. If an ML model is used, learn preprocessing decisions and choose hyperparameters within training partitions; prevent participant and temporal leakage.
8. **Handoff:** Export versioned derivatives, configuration, annotations/component decisions, retention summaries, before/after QC, software and source identities, timestamps and review state. Record limitations. A technically completed pipeline is not automatic scientific acceptance. Keep the identity branch and justified alternatives for sensitivity review.
