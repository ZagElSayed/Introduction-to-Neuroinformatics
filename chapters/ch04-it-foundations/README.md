# ch04 it foundations — hands-on laboratory

**Notebook:** [04_provenance_pipeline.ipynb](04_provenance_pipeline.ipynb)

**Learning objective:** Build an auditable, deterministic analysis derivative with checksum and provenance.

**Data:** Synthetic data with deterministic random seed; local outputs only.

## Run

1. From the repository root, install `pip install -r requirements.txt`.
2. Launch `jupyter lab` and open the notebook above.
3. No download is required; the notebook generates synthetic teaching data.
4. Run cells in order. Save observations, versions, parameter changes, and figures in your local lab report.
