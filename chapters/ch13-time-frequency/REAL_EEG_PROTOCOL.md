# Real EEG spectral and time–frequency protocol

This advanced exercise uses an appropriately licensed or instructor-approved recording and a documented research question. Preserve the accepted Chapter 12 derivative. Record actual software versions and check the matching documentation. A resting recording without suitable events cannot support a task ERP/ERD design.

1. **Contract and intake:** Define population, channels/ROI, usable duration/trials, absolute or relative endpoint, exact bands/denominator, event timing, baseline, exclusion rules, statistics and sensitivity comparisons. Verify units, sample rate, reference, acquisition/preprocessing filters, artifact decisions, discontinuities and input identities. Convert volts to microvolts explicitly when reporting corresponding squared units.
2. **PSD:** Compare justified segment durations with fixed conventions: explicit taper array, actual overlap/hop, detrend, FFT length, sidedness, density scaling, averaging and unused samples. Do not let a software default choose a different taper or averaging convention unnoticed. Calculate band integrals on linear PSD with documented boundaries/quadrature. Report resolution-related bandwidth separately from grid spacing and examine residual line/muscle contamination.
3. **Peak and background:** Inspect the original waveform and PSD. A maximum within a predefined band is a candidate, not proof of an oscillation. If fitting periodic/aperiodic structure, declare the positive-frequency range, fixed/knee model, peak limits, excluded contaminated frequencies, software/model version and diagnostics. Inspect residuals; represent absent or unreliable peaks as missing/review-required rather than forcing a number.
4. **Time–frequency estimation:** For STFT, state window duration, hop, padding, time-center convention and normalization. For Morlet analysis, state frequencies, cycles, zero-mean convention, support/truncation and decimation. Distinguish `cycles/frequency` as an intuitive scale from actual Gaussian support. Keep sufficient surrounding data and mask unsupported edges; longer low-frequency support can contaminate a nominal baseline with later activity. Inspect any downsampling/decimation for aliasing.
5. **Trial averaging and baseline:** Specify whether power is computed per trial and averaged, or computed after averaging complex coefficients/the waveform. Total trial power and power of the phase-locked average answer different questions. Define baseline sample inclusivity, pooling within/across trials, positivity checks, ratio/percent/dB transform and averaging order. Keep an absolute-power comparison and document unequal baseline quality. A display reference to a plot maximum is not an event-related baseline.
6. **Independence and multiplicity:** State the unit of inference. Overlapping windows, trials within a participant, channels and time-frequency cells are not independent participants. Use participant-aware summaries or an appropriate hierarchical design, report usable data per participant/condition, and justify correction for the tested search space. A significant cluster does not make every cell a separately significant effect or locate an exact onset. Keep exploratory selection distinct from confirmatory testing.
7. **Scientific QC and handoff:** Inspect representative raw/processed traces, PSDs, TFRs, retained duration/trials, baseline validity, edge support, aperiodic fits when used, and effects of plausible alternatives. Export versioned tables/maps and provenance linking input, configuration, software, channel/ROI definitions, denominators, decisions, code and reviewer. Keep failed, absent-feature and pending-review cases distinct. Do not use the result diagnostically on the strength of this exercise.
