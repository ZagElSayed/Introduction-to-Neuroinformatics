# ch01 foundations — hands-on laboratory

**Notebook:** [01_eeg_first_look.ipynb](01_eeg_first_look.ipynb)

**Learning objective:** Inspect a real recording, identify its sampling rate and units, and visualize a short EEG segment.

**Data:** PhysioNet EEGMMIDB S001R01.edf (eyes-open baseline) — [original source](https://physionet.org/content/eegmmidb/1.0.0/), version 1.0.0, DOI [10.13026/C28G6P](https://doi.org/10.13026/C28G6P).

## Run

1. From the repository root, install `pip install -r requirements.txt`.
2. Launch `jupyter lab` and open the notebook above.
3. Download S001R01.edf from PhysioNet and put it in the notebook working directory.
4. Run cells in order. Save observations, versions, parameter changes, and figures in your local lab report.
