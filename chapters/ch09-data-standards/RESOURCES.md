# Chapter 9 primary resources

Consult the applicable current specification for implementation. The lab declares BIDS 1.11.2 for its teaching example, but does not supply the files needed to establish conformance.

| Resource | Use in this chapter |
| --- | --- |
| [BIDS common principles](https://bids-specification.readthedocs.io/en/stable/common-principles.html) | Formats, entities, metadata, inheritance, and missing values. |
| [BIDS event specification](https://bids-specification.readthedocs.io/en/stable/modality-agnostic-files/events.html) | Seconds, time origin, duration, negative onset, and corresponding task files. |
| [BIDS EEG specification](https://bids-specification.readthedocs.io/en/stable/modality-specific-files/electroencephalography.html) | Recording formats, channels, acquisition metadata, electrodes, and coordinate records. |
| [Official BIDS Validator](https://github.com/bids-standard/bids-validator) | Formal specification checks for real BIDS datasets; separate from this teaching validator. |
| [W3C PROV overview](https://www.w3.org/TR/prov-overview/) | Provenance entities, activities, and agents. |
| [NIST Secure Hash Standard](https://doi.org/10.6028/NIST.FIPS.180-4) | Cryptographic digests and integrity concepts. |
| [Python csv](https://docs.python.org/3/library/csv.html), [json](https://docs.python.org/3/library/json.html), [hashlib](https://docs.python.org/3/library/hashlib.html) | The standard-library building blocks used in the lab. |
| [DICOM introduction](https://dicom.nema.org/medical/dicom/current/output/html/part01.html) | Clinical imaging organization and exchange. |
| [NIfTI documentation](https://nifti.nimh.nih.gov/nifti-1/documentation) | Arrays, headers, and spatial interpretation. |
| [HDF5 introduction](https://support.hdfgroup.org/documentation/hdf5/latest/_intro_h_d_f5.html) | Groups, arrays, attributes, and the distinction between a container and a scientific schema. |

Use synthetic data for this public exercise. Institutional clinical workflows require their own approved procedures, controls, and scientific review.
